# Signal Discovery

Welcome to the Signal Discovery pipeline. Upload a dataset or point me to a file to get started.

**What I can do:**

- **Inspect & profile** datasets (CSV, Parquet, JSON)
- **Segment** data by categorical dimensions with quality scoring
- **Discover baselines** — trend, seasonality, and residual decomposition
- **Detect anomalies** — deviations from expected patterns
- **Forecast** with confidence intervals and scenario analysis
- **Correlate signals** across multiple datasets

**Quick start:** Try typing *"Inspect the dataset at data/all-beer.csv"*
